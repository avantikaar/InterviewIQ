# InterviewIQ Knowledge Base

## Python fundamentals
A Python list is mutable and ordered. A tuple is ordered and immutable. Lists suit collections that change; tuples suit fixed records. Exception handling uses try, except, else and finally. Catch specific exceptions, log useful context, and avoid silently swallowing errors.

## APIs and backend engineering
A REST API exposes resources through HTTP methods such as GET, POST, PUT, PATCH and DELETE. Good API design uses clear resource paths, correct status codes, input validation, consistent responses, authentication and useful errors. Keep secrets on the server.

## SQL and databases
Indexes can improve reads but consume storage and may slow writes. Use EXPLAIN to inspect query plans. Parameterized queries help prevent SQL injection. Transactions group related changes atomically.

## Data structures and algorithms
A hash table typically provides average O(1) lookup, insertion and deletion. A stack is last-in, first-out; a queue is first-in, first-out. Explain time and space complexity.

## Machine learning fundamentals
Overfitting occurs when a model performs well on training data but poorly on unseen data. Mitigations include cross-validation, regularization, simpler models and more representative data. Data leakage occurs when information unavailable at prediction time affects training or evaluation.

## Behavioural interview structure
Use Situation, Task, Action, Result. Explain your own contribution, the decision made and what you learned. Be specific and do not invent achievements.

## Responsible assessment
Evaluate only job-related answer content against a transparent rubric. Never score accent, voice pitch, speed, identity, disability, age, gender or other protected traits. Keep human reviewers responsible for hiring decisions.
